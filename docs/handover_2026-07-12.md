# Session Handover — 2026-07-12

## What was built

### Voice Presets
- **Backend:** `server/presets.js` — Node-managed engine-scoped JSON files in `presets/<engine>.json`
- **API:** `POST /v1/voices/preset` (create/update), `DELETE /v1/voices/:id` (also deletes presets), `GET /v1/voices?engine=` (includes presets as `voice_type: "preset"`)
- **Speech handler:** `server/api/speech.js` — auto-resolves preset IDs to base voice + instructions before forwarding to engine
- **Dashboard:** Gemini/xAI voices pages are preset management UIs (create form, preview, save, delete). Presets appear in generate page voice dropdowns as a "Presets" group.

### Client SDK
- `lib/nspeech-client/nspeech-client.js` — vanilla JS, zero dependencies. Covers: `speech()`, `speechClone()`, `listVoices()`, `cloneVoice()`, `previewVoice()`, `mixVoices()`, `deleteVoice()`, `createPreset()`, `deletePreset()`, `listPresets()`, `switchEngine()`, `listEngines()`, `getEngine()`, `getStatus()`.
- Includes `playSpeechStream()` helper for queue-based streaming playback.
- Gemini generate page refactored to use SDK (60% fewer lines).

## Gotchas
- **File encoding:** `create_file` is the only reliable way to create clean UTF-8 files. `git restore` and file-copy often produce UTF-16 with BOM corruption.
- **NUI select:** Must query the `<nui-select>` wrapper (not inner `<select>`) before calling `setItems()`. Component won't be upgraded when `init()` runs — use `element.show` for data loading.
- **Cloud adapters:** Don't have `engineName` property — use `body.model` or query params for engine identification.
- **Server restart:** Required after pulling backend changes (new routes, new modules).
